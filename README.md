# Live House Café - Repositorio documental

Repositorio documental del proyecto académico **Live House Café**, una aplicación web para apoyar la operación de un bar mediante gestión de usuarios, inventario de bebidas, pedidos, facturación y pagos.

## Estructura

- **Inicio/**: propuesta y documentos iniciales del proyecto.
- **Planeación/**: arquitectura, diseño y modelo entidad-relación.
- **Ejecución/**: historias de usuario y Product Backlog.
- **Monitoreo y control/**: evidencias de QA y validación.
- **Cierre/**: documentos y enlaces finales de entrega.

## Tecnologías principales

Laravel, Blade, MVC, MySQL, Docker y Railway.
